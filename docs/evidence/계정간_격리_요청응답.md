# 자리 간 자료 격리 — 양방향 (C36–C40)

```http
자리A 항목 3건 생성 → 자리B 항목 3건 생성
DELETE /api/items/{B의 항목}   (자리A 세션) -> 404 {"error":"찾지 못했습니다."}
DELETE /api/items/{A의 항목}   (자리B 세션) -> 404 {"error":"찾지 못했습니다."}
GET /api/items?user_id=SPACE_B&owner=SPACE_B (자리A 세션) -> 200, 돌아온 건수 3 (자리A 것만)
자리A 건수: 삭제 시도 전 3 → 후 3
자리B 건수: 삭제 시도 전 3 → 후 3
```

> 거절을 만드는 소스: `lib/repository/item.ts` — 모든 함수가 첫 인자 `spaceId` 로만 키를 만들고,
> 단건 삭제는 `item.spaceId === 세션 spaceId` 확인 후에만 실행한다. `spaceId` 는 `lib/session.ts:getSessionUser()`(쿠키 전용)에서만 온다.

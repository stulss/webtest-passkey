# 패스키 2개 등록, 하나 삭제 (C42 / C44 / C45)

```http
GET  /api/passkeys                     -> 200, 개수 2
DELETE /api/passkeys/{패스키1}          -> 200
POST /api/webauthn/authenticate/verify  (남은 패스키2)   -> 200
POST /api/webauthn/authenticate/verify  (삭제된 패스키1) -> 400 {"error":"등록되지 않은 패스키입니다."}
DELETE /api/passkeys/{패스키2 = 마지막} -> 409 {"error":"마지막 패스키는 삭제할 수 없습니다. 자리를 지우려면 '비공개 자리 삭제'를 사용하세요."}
```

# 이미 쓴 challenge 재사용 거절 (C31 / C33)

```http
POST /api/webauthn/authenticate/options                  -> 200, Set-Cookie: to8_webauthn=<redacted>
POST /api/webauthn/authenticate/verify  (challenge 첫 사용) -> 200 {"ok":true}
POST /api/webauthn/authenticate/verify  (같은 challenge 재사용) -> 400 {"error":"로그인 요청을 찾지 못했습니다. 다시 시도하세요."}
```

> verify 라우트는 서명 검증 전에 `challenge.consume`(`GETDEL`) 로 challenge 를 원자적으로 소비한다.
> 소비된 challenge 로 다시 오면 `GETDEL` 이 nil 이라 400.

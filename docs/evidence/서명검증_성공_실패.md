# 저장된 공개키로 서명 검증 — 성공과 실패 (C29 / C30)

```http
POST /api/webauthn/register/verify  (자리A 패스키1)      -> 201
POST /api/webauthn/authenticate/verify  (정상 서명)      -> 200 {"ok":true}
POST /api/webauthn/authenticate/verify  (1바이트 변조 서명) -> 401 {"error":"로그인하지 못했습니다."}
```

> 성공한 로그인은 서버가 `cred:{id}` 에 저장해 둔 공개키로 `verifyAuthenticationResponse` 를 통과한 것이고,
> 1바이트만 바꾼 서명은 같은 경로에서 거절된다.

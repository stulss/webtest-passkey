## POST /api/webauthn/authenticate/verify — 요청 본문

```json
{
  "response": {
    "id": "wjpQLHOshXy6Lpmv0mBNVyeFQV8",
    "rawId": "wjpQLHOshXy6Lpmv0mBNVyeFQV8",
    "type": "public-key",
    "response": {
      "clientDataJSON": "eyJ0eXBlIjoid2ViYXV0aG4uZ2V0IiwiY2hhbGxlbmdlIjoiWHJuLVNiWjA1X1U1MklOcFc1QUJkajNWc0xFM2dLQ3FxdTloekY4a0VjSSIsIm9yaWdpbiI6Imh0dHBzOi8vd2VidGVzdC1wYXNza2V5LnZlcmNlbC5hcHAiLCJjcm9zc09yaWdpbiI6ZmFsc2V9",
```

- `signature` 는 개인키로 만든 **서명**이지 개인키가 아니다.
- 서버는 이 서명을 `cred:{id}.publicKey`(저장된 공개키)로 검증한다 → `lib/webauthn.ts:checkAuthentication`
- `userHandle` 은 이 문서에서 가렸다 (C34).

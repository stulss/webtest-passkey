# AI와 내 판단 3줄 (과제 8)

**① AI에게 맡긴 일**
과제 1(webtest) 정적 사이트의 Next.js 이식, `@simplewebauthn` 서버·브라우저 연동(등록·로그인 ceremony),
불투명 세션·자리 격리 로직, P-256 소프트웨어 인증기와 자동 검증 스크립트, 문서 초안 작성.

**② 내가 직접 판단한 일**
회원가입을 만들지 않고 "패스키를 처음 등록하면 그 사람 몫의 비공개 자리가 생긴다"로 모델을 정한 것,
등록 시 입력은 패스키 이름 한 칸뿐으로 제한한 것, 비공개 항목은 추가·삭제만 두고 수정 기능을 뺀 것,
마지막 패스키는 삭제할 수 없게(계정 잠김 방지) 한 것, 저장소를 관계형 DB 대신 Redis(KV)로 정하고
새 저장소·Vercel 프로젝트로 분리한 것.

**③ AI 제안을 따르지 않은 일**
AI가 처음 설계에 넣었던 "계정 이름 입력칸"과 "비공개 노트 수정 기능(CRUD)"을, 과제 8이 요구하지 않는
범위라고 판단해 걷어냈다. AI가 대안으로 제시한 비밀번호 폴백·이메일 복구도 넣지 않았고, 대신 "모든 기기를
잃으면 복구할 수 없다"를 인증 구현 설명서 ⑥의 첫 항목으로 명시했다.
